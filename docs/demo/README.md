# Guion de exposición en vivo

El video no se realiza por solicitud del equipo. El requisito del docente se mantiene registrado como pendiente y `portal.yml` no anuncia un enlace inexistente.

## Recorrido del aplicativo

1. Explicar el problema de solicitudes dispersas y los roles.
2. Mostrar departamentos, agentes y supervisores.
3. Registrar una solicitud desde una cuenta de cliente.
4. Asignarla desde el administrador y explicar la sugerencia por carga.
5. Mostrar el acceso exclusivo del agente, una nota interna y una solución propuesta.
6. Volver al cliente, consultar sus avisos y confirmar con una valoración.
7. Mostrar reportes y CSV, la regla SLA y el diagnóstico MongoDB Redis.

Usar cuentas ficticias y un ticket propio de la demostración. No modificar los casos anteriores del grupo. Si no hay red, explicar la situación y utilizar las capturas documentadas como evidencia, sin presentarlas como una conexión en vivo.
