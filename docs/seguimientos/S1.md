## Problema usuarios y MVP

OpenDesk centraliza consultas, reclamos, devoluciones, garantías y problemas
con pedidos. Permite asignar responsables y conservar prioridades, plazos e
historial. El cliente presenta y consulta sus casos; el agente atiende sus
tickets asignados o propios; el administrador gestiona cuentas, recursos,
asignaciones, política SLA, reportes y auditoría.

**Entra:** autenticación, tres roles, tickets, clientes, catálogo, historial,
SLA, CSV, auditoría, caché y solicitudes locales pendientes de sincronización.

**No entra:** pagos, inventario, adjuntos, chat, correo SMTP, MFA, recuperación
por enlace, calendario laboral ni sincronización automática Webmin–Atlas.

## Arquitectura y modelo v1

| Componente | Responsabilidad | Evidencia |
|---|---|---|
| PHP | API, permisos, sesiones y reglas | [Aplicación](../../src/app.php) |
| MongoDB | Cuentas, contactos, catálogo, tickets, historial, SLA y auditoría | [Modelo de datos](../modelo-datos.md) |
| Redis | Cola priorizada con TTL y contadores temporales | [Rutas](../../src/routes.php) |
| IndexedDB y service worker | Vista guardada y solicitudes pendientes | [Arquitectura](../arquitectura/README.md) |

MongoDB local y Atlas son perfiles alternativos del mismo motor. No se
cuentan como motores distintos ni se replican automáticamente. Redis tiene
una función temporal; si falla, la aplicación consulta MongoDB. No se usa SQLite.

## Reproducir y verificar la versión

```bash
git clone https://github.com/vanems96/ProyectoOpenDesk.git
cd ProyectoOpenDesk
git checkout v0.1.0
php tests/roles.php
git show v0.1.0:docs/seguimientos/S1.md
git show --no-patch v0.1.0
```

Para ejecutar la aplicación completa, seguir la [instalación](../../README.md):
PHP compatible, extensión MongoDB y configuración privada fuera de la raíz web.
.env.example es una plantilla y no se carga automáticamente.
