## Completado en código

- Integración Redis con tres estructuras: string, sorted set y hash.
  Prefijo grupo3: obligatorio, expiración e invalidación por versión.
- Contingencia hacia MongoDB cuando Redis rechaza conexión, autenticación,
  selección o PING, o falla durante una operación de caché.
- Herramienta de medición con tres operaciones, muestras individuales y
  mediana; scripts/measure.php. Datos aislados y limpieza por ejecución.
- Índices compuestos, consulta explain con executionStats y aggregation
  pipeline por prioridad. Ver src/integration.php.
- Decisiones en docs/decisiones.md y protocolo en docs/mediciones/protocolo.md.
- Pruebas de controladores, conexión simulada, prefijo, tipos, esquemas y mediana.
- Job de CI preparado con servicios MongoDB y Redis efímeros. La definición
  del workflow no equivale a que su ejecución ya haya resultado exitosa.
