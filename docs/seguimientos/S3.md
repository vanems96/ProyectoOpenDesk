## Qué funciona en el despliegue

MongoDB local del servidor mantiene la base grupo3_db. Redis guarda caché
temporal, con string, sorted set y hash, TTL e invalidación por versión.
El diagnóstico verificó las tres estructuras y TTL; la interfaz mostró Redis
disponible y la cola SLA devolvió origen Redis en la segunda lectura.
No se instaló la extensión ni se modificaron permisos del servidor.
Las fechas visibles y CSV usan dd/mm/aaaa, con hora y zona de Costa Rica.

El flujo registrar, asignar y resolver se verificó en Webmin con cuentas
separadas; el CRUD completo, aislamiento entre clientes, permisos, reapertura
y CSV se comprobaron en CI aislado. Las evidencias de cada entorno se distinguen.

## Mediciones y límites

Se ejecutó php index.php --benchmark 100 3 en Webmin. Se conservaron muestras,
medianas, explain y agregación. Se usaron datos sintéticos separados y se
limpió solo la ejecución. Los valores y su interpretación están en la tabla
enlazada; no se extrapolan a otros servidores, Atlas ni carga concurrente.

## Limitación reprogramada con justificación

JSON Schema está implementado y probado en CI. En Webmin se verificaron cero
documentos incompatibles y se guardó respaldo privado, pero MongoDB rechazó
collMod por permisos. La activación se reprograma al administrador como tarea
posterior; no se presenta como terminada ni se altera el acceso para obtenerla.
La validación PHP permanece activa. Esta operación administrativa adicional
no figura como requisito independiente en la lista de S3 del docente.

Los Issues #13, #14 y #15 conservan la evidencia del cierre o reprogramación.
La etiqueta v0.3.0 identifica la entrega de S3; no mueve v0.1.0 ni v0.2.0.
